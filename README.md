## Running the Exercises

For HTML and CSS exercises, open the corresponding `index.html` or HTML file in a web browser.

For React applications, navigate to the folder containing `package.json` and run:

```bash
npm install
npm run dev
```

Then open the local development address displayed in the terminal.
